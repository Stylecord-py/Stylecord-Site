# Instalação

## Requisitos

- Python instalado (confira a versão mínima no repositório oficial).
- Um token de bot criado no Portal de Desenvolvedores do Discord.

## Obter a biblioteca

> **Planejado:** os comandos abaixo são modelos. Substitua pela URL real do repositório ou pelo nome do pacote no PyPI, se já estiver publicado.

```bash
git clone URL_DO_REPOSITORIO
cd stylecord.py
pip install -e .
```

## Ambiente virtual

```bash
python -m venv .venv
```

Depois, siga para o [Primeiro bot](#/getting-started/first-bot).
