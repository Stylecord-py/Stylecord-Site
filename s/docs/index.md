# Visão geral

Stylecord.py é uma biblioteca Python independente, criada do zero, para desenvolver bots de Discord com agilidade e código organizado.

> **Aviso:** esta documentação é uma base inicial. Cada página marca o que está confirmado e o que é planejado. Nada aqui deve ser lido como API estável até ser conferido com o repositório oficial.

## Filosofia

- Rapidez no desenvolvimento, sem prometer números de desempenho.
- Estrutura clara e curva de aprendizado acessível.
- Flexibilidade para bots de tipos diferentes.
